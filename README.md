# Clock26 · 锁屏时钟字体拉伸小插件

一个极简越狱插件：把锁屏大时间的数字换成 Apple 可变字体 **axs66**，用它自带的可变轴做**大小 / 拉高 / 宽度 / 粗细**四种矢量变形——数字任意放大变形都清晰不糊。数字的**顶部始终锚定在日期正下方、只向下生长**，永远不会居中、不会上顶、也不会被原时间区域裁掉。锁屏通知一多，时钟还会**自动缩回**，不被通知盖住。

- **可调大小 / 拉高 / 宽度 / 粗细**：大小（整体放大 0.5–3.0 倍）、拉高（HGHT 高度轴 100–500）、宽度（wdth 宽度轴 60–100）、粗细（wght 字重轴 1–1000）。
- **向下生长、锚定日期下方**：放大 / 拉高时标签顶部固定在系统给的原顶部，只向下撑，越大越往下——永远不会顶进日期、不会被裁掉，也**不会跑到屏幕中间**。
- **粗细可调**：粗细走字体原生 `wght` 字重轴，1 = 最细、400 = 常规、1000 = 最粗，笔画加粗后依旧是矢量、清晰不糊。
- **通知自适应**：通知多到系统压窄时间区域时，插件检测到容器变矮就把时钟平滑缩回接近原始大小，避免放大的数字被下面的通知盖住；通知消失后自动恢复。
- **纯矢量变形，清晰不糊**：全部靠字体自身的四个可变轴 + 点数放大，不再用任何仿射拉伸，放到很大也不模糊、不发虚。
- **不再被切**：放大 / 拉高后系统给的原时间框太小会切字。插件会**让标签框贴合字形、顶部锚定向下长**，并沿视图链一路到 window **关闭 `clipsToBounds` / `masksToBounds` 并清掉时间区域的 layer 遮罩**，数字溢出原区域也能完整显示。
- **不弹回默认**：每一次 `layoutSubviews` 都重新贴回字体和撑框，配合签名守卫（相同参数直接跳过），系统刷新绝不会把它冲掉。
- **随时可关**：关闭后立即恢复系统原字体、原始 frame，不留痕迹。

## 原理

系统里藏着一支可变字体 axs66（内部名 `.SF Adaptive Soft Numeric`），带四个可变轴：

| 轴 | 范围 | 作用 | 本插件 |
|------|--------|------|--------|
| **HGHT** | 100–500 | 高度 | ✅「拉高」滑块 |
| **wdth** | 60–100 | 宽度 | ✅「宽度」滑块 |
| **wght** | 1–1000 | 字重 / 粗细 | ✅「粗细」滑块 |
| SOFT | 0–100 | 圆润度 | 固定 70 |

整体「大小」是在原始字号上乘一个倍数（0.5–3.0）矢量放大。宽度、粗细分别直接驱动字体原生的 `wdth`、`wght` 轴，全程矢量变形、无任何仿射拉伸。为避免与系统隐藏字体同名冲突，随插件附带的 `AXS66Clock.otf` 已用 `rename_font.py` 改名为 `AXS66Clock`（fvar 可变轴保持不变）。插件在进程内用 `CTFontManagerRegisterFontsForURL` 注册它，再对 `CSProminentTimeView` 里最大的数字标签换上带可变轴的 `UIFontDescriptor`，同时撑开标签框、顶部锚定并解除祖先裁剪。

## 为什么之前会「跑到屏幕中间」/「一超出区域就不显示」

- **跑到屏幕中间**：旧版把标签框撑得比文字高很多（1.6 倍），而 `UILabel` 默认会把单行文字**纵向居中**——文字就掉到那个大框的中间去了，看着像居中在屏幕上。新版让标签框**贴合文字实际高度**、把框的顶部钉在系统给的原顶部（也就是日期正下方），框内居中此时就等于贴在顶部，数字于是稳稳挂在日期下面，只向下生长。
- **一超出区域就不显示**：iOS 给锁屏时间容器既开了 `clipsToBounds`，又在 layer 上挂了显式遮罩。字号一放大、HGHT 一拉高，字形超出系统按原字号算好的小方框就被裁掉。插件在每次布局里沿视图链到 window 逐层 `clipsToBounds = NO`、`masksToBounds = NO`，并清掉最近几层的 `layer.mask`，溢出也能完整显示。

## 通知过多时怎么办

锁屏通知一多，系统会把 `CSProminentTimeView` 压矮给通知让位。插件记录它在"没有通知、最宽敞"时的高度，一旦当前高度掉到该值的一定比例（默认 55%）以下，就按压缩程度把"放大 / 拉高 / 超宽"这些**超出原始的量**平滑缩回，直到接近系统原始大小——这样放大的时钟不会被下面的通知盖住；通知消失、容器恢复后又自动长回设定的大小。

## 用法

装好后到「设置 → Clock26」：

- **启用** 开关
- **大小**（倍）滑块：0.5–3.0，默认 1.0
- **拉高**（HGHT）滑块：100–500，默认 300
- **宽度**（wdth）滑块：60–100，默认 100（60 最窄、100 满宽）
- **粗细**（wght）滑块：1–1000，默认 400（400 常规、1000 最粗）
- 改完即时生效、无需注销；必要时点「注销 Respring」让改动彻底刷新

> 关于位置：早期版本试过「长按拖动 / 上下位置滑块」，但锁屏长按会和系统「进入壁纸编辑」冲突、偏移也常被系统布局盖掉，体验不稳定，已移除。现在改为**向下生长、锚定日期下方**——直接调大小 / 拉高 / 宽度即可，数字自然落在日期下面。
>
> 关于液态玻璃：曾加过 iOS 26 的 `UIGlassEffect` 玻璃底，但那只在 iOS 26+ 生效，且和 BigTime 的自研 Metal 玻璃（折射 / 色散 / 高光，iOS 14+ 都能用）不是一回事，效果达不到预期，已移除。

## 编译

### GitHub Actions（推荐）
推送到仓库后 Actions 自动编译 rootless + roothide 两个 deb，在 Artifacts 里下载。

### 本地 Theos
```bash
# rootless
make clean && make package FINALPACKAGE=1 THEOS_PACKAGE_SCHEME=rootless

# roothide
make clean && make package FINALPACKAGE=1 THEOS_PACKAGE_SCHEME=roothide
```
